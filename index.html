Step 1: Number Matrix

This matrix contains sequential numbers from 1 to n² (where n is the order). It serves as a lookup table. We'll use the row and column identifier matrices to determine which number from this matrix goes into each cell of the final magic square.

Step 2a: Row Identifier Matrix

The middle column is numbered 1 to n (top to bottom). Columns on either side get values by adding/subtracting 1, with wrapping (modulo arithmetic). This matrix tells us which ROW to look at in the number matrix for each position.

Step 2b: Column Identifier Matrix

This is a mirror image (horizontal flip) of the row identifier matrix. This matrix tells us which COLUMN to look at in the number matrix for each position.

Final Magic Square

For each position (i,j), we look at row_matrix[i][j] and column_matrix[i][j] to get row and column identifiers. We then look up number_matrix[row][column] to get the value for that position. All rows, columns, and diagonals sum to the magic constant!
